### Задача 1.3: Букву в число
#### Текст задачи
Дана сигнатура метода: `public int charToNum (char x);`  
Метод принимает символ `x`, который представляет собой один из `"0123456789"`. Необходимо реализовать метод таким образом, чтобы он преобразовывал символ в соответствующее число. Подсказка: код символа `'0'` это число 48.  
Пример: `x = '3'`, результат: `3`.
#### Алгоритм решения
Выполняется арифметическая операция вычитания символа `'0'` из входящего символа `x` (`x - '0'`). По таблице ASCII символьные цифры идут подряд, поэтому разность их кодов дает целое число.

### Задача 1.6: Большая буква
#### Текст задачи
Дана сигнатура метода: `public bool isUpperCase (char x);`  
Необходимо реализовать метод таким образом, чтобы он принимал символ `x` и возвращал `true`, если это большая буква в диапазоне от `'A'` до `'Z'`.  
Пример 1: `x = 'D'`, результат: `true`.  
Пример 2: `x = 'q'`, результат: `false`.
#### Алгоритм решения
Используется двойная проверка диапазона ASCII-кодов с помощью логического оператора И (`&&`): `x >= 'A' && x <= 'Z'`. Если символ входит в этот интервал включительно, возвращается `true`.

### Задача 2.4: Строка сравнения
#### Текст задачи
Дана сигнатура метода: `public String makeDecision (int x, int y);`  
Необходимо реализовать метод таким образом, чтобы он возвращал строку, которая включает два принятых методом числа и корректно выставленный знак операции сравнения (больше, меньше, или равно).  
Пример 1: `x = 5`, `y = 7`, результат: `"5 < 7"`.  
Пример 2: `x = 8`, `y = -1`, результат: `"8 > -1"`.  
Пример 3: `x = 4`, `y = 4`, результат: `"4 == 4"`.
#### Алгоритм решения
Каскадная конструкция `if - else if - else` сравнивает значения `x` и `y`: при `x > y` конструируется строка вида `"x > y"`, при `x < y` — `"x < y"`, а в остальном случае — `"x == y"`.

### Задача 2.5: Тройной максимум
#### Текст задачи
Дана сигнатура метода: `public int max3 (int x, int y, int z);`  
Необходимо реализовать метод таким образом, чтобы он возвращал максимальное из трех полученных методом чисел. Подсказка: идеальное решение включает всего две инструкции `if` и не содержит вложенных `if`.  
Пример 1: `x = 5`, `y = 7`, `z = 7`, результат: `7`.  
Пример 2: `x = 8`, `y = -1`, `z = 4`, результат: `8`.
#### Алгоритм решения
Переменной `max` присваивается первое значение `x`. Далее с помощью двух последовательных неблокирующих инструкций `if` происходит поочередная проверка: если `y > max`, обновляется `max = y`; затем если `z > max`, обновляется `max = z`. По завершении возвращается `max`.

### Задача 3.6: Одинаковость
#### Текст задачи
Дана сигнатура метода: `public bool equalNum (int x);`  
Необходимо реализовать метод таким образом, чтобы он возвращал `true`, если все знаки числа одинаковы, и `false` в ином случае. Подсказки: `int x = 123 % 10;` // `x` будет иметь значение 3; `int y = 123 / 10;` // `y` будет иметь значение 12.  
Пример 1: `x = 1111`, результат: `true`.  
Пример 2: `x = 1211`, результат: `false`.
#### Алгоритм решения
Из числа извлекается последняя цифра через остаток от деления на 10 (`x % 10`). Затем в цикле `while (x > 0)` число последовательно делится на 10 (`x /= 10`), и каждая очередная последняя цифра сравнивается с исходной. При найденном расхождении метод сразу возвращает `false`, а при успешном завершении цикла — `true`.

## Задание 4. Массивы

### Задача 4.1: Поиск первого значения
#### Текст задачи
Дана сигнатура метода: `public int findFirst (int[] arr, int x);`  
Необходимо реализовать метод таким образом, чтобы он возвращал индекс первого вхождения числа `x` в массив `arr`. Если число не входит в массив возвращается -1.  
Пример: `arr = [1, 2, 3, 4, 2, 2, 5]`, `x = 2`, результат: `1`.
#### Алгоритм решения
Выполняется линейный проход по массиву с помощью цикла `for` от индекса `0` до `arr.length - 1`. При первом же совпадении `arr[i] == x` метод мгновенно возвращает индекс `i`. Если цикл завершился без совпадений, возвращается `-1`.

### Задача 4.2: Поиск последнего значения
#### Текст задачи
Дана сигнатура метода: `public int findLast (int[] arr, int x);`  
Необходимо реализовать метод таким образом, чтобы он возвращал индекс последнего вхождения числа `x` в массив `arr`. Если число не входит в массив возвращается -1.  
Пример: `arr = [1, 2, 3, 4, 2, 2, 5]`, `x = 2`, результат: `5`.
#### Алгоритм решения
Цикл `for` организуется в обратном направлении: от последнего индекса `arr.length - 1` до `0`. Первое найденное совпадение с конца будет являться последним вхождением элемента в массив, поэтому метод сразу возвращает данный индекс `i`.

### Задача 4.4: Добавление в массив
#### Текст задачи
Дана сигнатура метода: `public int[] add (int[] arr, int x, int pos);`  
Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, который будет содержать все элементы массива `arr`, однако в позицию `pos` будет вставлено значение `x`.  
Пример: `arr = [1, 2, 3, 4, 5]`, `x = 9`, `pos = 3`, результат: `[1, 2, 3, 9, 4, 5]`.
#### Алгоритм решения
Создается новый массив размером `arr.length + 1`. Первым циклом копируются элементы исходного массива до позиции `pos`. В ячейку `result[pos]` записывается значение `x`. Вторым циклом переносятся оставшиеся элементы со сдвигом на один индекс вправо (`result[i + 1] = arr[i]`).

### Задача 4.7: Возвратный реверс
#### Текст задачи
Дана сигнатура метода: `public int[] reverseBack (int[] arr);`

#### Алгоритм решения

### Задача 4.10: Удалить негатив
#### Текст задачи
Дана сигнатура метода: `public int[] deleteNegative (int[] arr);`
